# Elite Education — Meta Ads Landing Page

Files:
- index.html — landing page
- styles.css — responsive UI
- script.js — lead form, WhatsApp handoff, UTM persistence and tracking hooks

## Launch checklist
1. Replace the placeholder Meta Pixel ID in index.html.
2. Connect the form to your CRM/lead endpoint if you want server-side lead capture.
3. Configure Meta Conversions API through your server/CRM.
4. Add the final Elite Education logo and approved brand photography.
5. Verify every university/programme claim against the current admission cycle.
6. Test mobile speed, WhatsApp link, lead submission and UTM persistence.
7. Create a dedicated thank-you/conversion URL if your CRM requires one.

The page intentionally avoids promising that every programme is available at every university or that all programmes have identical recognition/eligibility. Those details should be confirmed per programme and intake.
